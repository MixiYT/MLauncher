# MLauncher Lite

Облегчённая версия MLauncher для Windows x64.

Скачайте MLauncher-Lite из [релизов](https://github.com/MixiYT/MLauncher/releases/latest), распакуйте ZIP и запустите MLauncher-Lite.exe.

Доступны Minecraft с модами, ресурспаки, карты, редактор и перенос сборок, ИИ-помощник, автоматические обновления и стили Material, Liquid Glass и Simple.
Фоны поддерживают изображения, GIF и простые эффекты.

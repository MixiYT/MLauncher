# Общий ИИ и режим разработчика

Раздел находится в **Настройки → Сервисы → ИИ-помощник → Режим разработчика**. Он есть в полной и Lite-версиях.

## Как устроены настройки

- Личные URL, модель и ключ пользователя сохраняются отдельно. Переключатель «Общий ИИ лаунчера» выбирает общий шлюз; личный ключ никогда не отправляется на этот шлюз.
- Новые установки выбирают общий ИИ. Старые настройки с собственным провайдером сохраняют личный режим.
- `config/ai-defaults.json` в ветке `main` задаёт только `revision`, `enabled`, `endpoint`, `model`. Лаунчер проверяет его при запуске, раз в час и по кнопке. Ошибка сети оставляет последний валидный конфиг. Более старая ревизия игнорируется.
- Микропатч применяется только в версиях, поддерживающих эту функцию. Уже выпущенная 0.3.12 её не содержит: пользователям сначала потребуется обновить сам лаунчер.
- Пул API-ключей хранится в Cloudflare Worker Secret `AI_KEYS`. Обновление пула сразу меняет обработку новых запросов всех пользователей; ZIP лаунчера для этого менять не нужно.
- Локальные поля разработчика сохраняются отдельно в `developer-keys.dat`, зашифрованном Windows DPAPI. Они не входят в `config.json`, экспорт сборок или публичный микропатч.

## Первое размещение Worker

1. Установите Node.js, откройте терминал в `worker` и выполните `npm ci`.
2. Выполните `npx wrangler login` и войдите в свой аккаунт Cloudflare в браузере.
3. Выполните `npm run deploy`. Сохраните выданный HTTPS адрес `mlauncher-ai.<ваш-поддомен>.workers.dev`.
4. В Cloudflare создайте API token с доступом **Account → Workers Scripts → Edit** только к нужному аккаунту. Вводите его в поле режима разработчика, не в чат и не в GitHub.
5. В лаунчере укажите Account ID, имя Worker `mlauncher-ai`, токен Cloudflare и несколько ключей OpenRouter. Нажмите «Сохранить локально (DPAPI)», затем «Отправить пул ключей в Cloudflare Secrets».
6. В публичном конфиге укажите адрес Worker с `/v1/chat/completions`, модель `openrouter/free`, увеличьте ревизию и включите общий ИИ. Экспортируйте JSON и обновите `config/ai-defaults.json` в `main` на GitHub. Ключей в этом файле нет.

Можно задать Secret и вручную: `npx wrangler secret put AI_KEYS`, затем ввести JSON-массив ключей интерактивно. Не передавайте значения ключей аргументами командной строки. При повторном развёртывании кода существующие Secrets сохраняются.

`ALLOWED_MODELS` в `worker/wrangler.jsonc` перечисляет разрешённые модели через запятую. Изменение модели в публичном конфиге не расширяет этот список автоматически: сначала разрешите модель на сервере. По умолчанию используется бесплатный маршрутизатор OpenRouter.

## Ограничения общего доступа

Worker принимает только ограниченный OpenAI-совместимый запрос: сообщения, разрешённую модель, до 4000 выходных токенов и до 300 КиБ входного JSON. Произвольные upstream URL, инструменты, стриминг и запросы из браузеров отключены. Тела ошибок провайдера, заголовки и служебные поля не возвращаются клиентам.

Стандартные ограничения — 6 запросов в минуту на IP и 60 на общую группу в каждой точке Cloudflare. Эти лимиты приблизительные и не являются строгим мировым бюджетом; пользователи одного IP делят лимит. Публичный desktop-клиент не может хранить общий секрет аутентификации. Для большего масштаба добавьте индивидуальные аккаунты и строгий счётчик через Durable Objects.

Для каждого запроса выбирается один ключ из пула. Ошибка 429 возвращается пользователю с `Retry-After`, без переключения на другой ключ ради обхода квоты. Несколько ключей одного аккаунта не гарантируют увеличение лимитов провайдера. Не добавляйте платные модели в общий шлюз без отдельного контроля бюджета. Запросы и журналы проходят через ваш Worker к OpenRouter; получатель показывается в помощнике, отправка начинается действием пользователя.

Проверки: `cargo test`, `cargo test --features lite`, `npm test` в `worker`, `npx wrangler deploy --dry-run`. Локальные тесты не подтверждают доступность реального аккаунта Cloudflare или квоты OpenRouter.

Официальные справочники: [Cloudflare Secrets](https://developers.cloudflare.com/workers/configuration/secrets/), [Rate Limiting](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/), [OpenRouter free router](https://openrouter.ai/openrouter/free), [лимиты OpenRouter](https://openrouter.ai/docs/api/reference/limits).

## Код доступа

При первом входе задайте локальный код длиной от 8 символов и повторите его. Следующие входы требуют этот код; после перезапуска и выключения режима разработчика управление блокируется. Есть отдельная кнопка блокировки. Неверный ввод задерживает повторную попытку на 3 секунды. Код в открытом виде не сохраняется: проверочное значение с индивидуальной солью хранится вместе с настройками под DPAPI. До разблокировки поля пула, Cloudflare-токен, экспорт и загрузка пула недоступны. Это локальная блокировка интерфейса, а не замена прав Cloudflare: пользователи не получают серверный пул и не могут управлять им без вашего токена Cloudflare. На другом компьютере пользователь может задать собственный локальный код, но это не даёт доступа к вашему серверу.

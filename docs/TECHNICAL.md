# Техническая документация MLauncher

[Пользовательское описание](../README.md)

## Реализовано

- Компактная центральная панель. Аккаунты, версии, моды и настройки открываются рядом на том же экране, без отдельных окон. Служебные кнопки — нарисованные иконки с подсказками.
- Встроенные панели растягиваются за края и нижний правый угол; размер каждой панели сохраняется отдельно. Можно держать открытыми две страницы сразу: предыдущая остаётся слева, новая открывается справа. Повторное нажатие иконки закрывает нужную страницу, клик по свободному фону — обе.
- Нативный оверлей Shift+Tab (полная Windows-версия): интерфейс рисуется внутри OpenGL-кадра игры, без отдельного окна и Minecraft-мода. Акцент/тема/простой фон берутся из лаунчера; клик вне окна закрывает оверлей.
- Полный список из официального манифеста Mojang: **Release / Snapshot / Beta / Alpha**, фильтры категорий, поиск по ID, кеш для оффлайн-просмотра.
- Отдельные инстансы для каждой версии и загрузчика: Vanilla / Fabric / Forge / NeoForge / Quilt. Папки называются как сборки в лаунчере.
- **Установка и запуск Minecraft**: библиотеки, нативы, ресурсы, Java, аргументы запуска, проверка лицензии, журнал процесса и кнопка остановки.
- **Java**: поиск установленных версий, ручной выбор, автоскачивание Temurin через Adoptium, память Xms/Xmx, G1/ZGC/Shenandoah, дополнительные JVM-аргументы, размер окна и полноэкранный режим.
- Поиск Modrinth без ключа; CurseForge через официальный API с вашим ключом.
- Иконки модов, описания, автор, число скачиваний и категории; сортировки, включая «Самые скачиваемые».
- **Проверка и установка обновлений модов** одним нажатием, с сохранением метаданных.
- **Отмена** установки/обновления модов и запуска игры.
- Разрешение обязательных зависимостей, проверка SHA-512/SHA-1, атомарная установка без перезаписи чужих JAR.
- Обычные аккаунты без пароля, Ely.by с 2FA и Microsoft device-code OAuth с проверкой лицензии Java.
- **Сессии сохраняются между запусками**: Ely.by обновляется через `/auth/refresh`, Microsoft — по refresh token; токены шифруются Windows DPAPI и не попадают в `config.json`.
- Скины Ely.by в игре через authlib-injector (включая оффлайн-аккаунт с флажком скинов).
- Четыре темы (Legacy/тёмная/светлая/AMOLED), акцент, прозрачность панелей, анимированный пейзаж и свой фон (PNG/JPG/WebP/BMP/GIF/видео через FFmpeg).
- Иконка окна, упакованный релизный EXE.

## Каталоги и редактор сборки

Моды и ресурспаки загружаются при открытии каталога. Поиск начинается через 350 мс после ввода; следующие результаты автоматически добавляются при прокрутке вниз. Переключение источника, сортировки или версии сбрасывает выдачу и прокрутку. При ошибке доступна повторная загрузка без потери уже полученных карточек.

В «Версии и сборки → Мои сборки» кнопка карандаша открывает редактор: название, отдельная Java, память, JVM-аргументы, окно игры, локальные моды и ресурспаки, миры и скриншоты. Моды можно импортировать, отключать и включать; скриншоты — просматривать и сохранять копию. Удаление в редакторе перемещает файлы в `launcher/trash` внутри сборки. Изменения файлов блокируются, пока эта сборка запущена. Переименование мира меняет имя его папки, а не NBT-поле названия мира.

Аватарки скинов сохраняются в `MLauncher-cache/full/avatars` или `MLauncher-cache/lite/avatars` рядом с EXE: свежий кеш используется сутки без скачивания, при ошибке сети остаётся прежняя картинка. Обе открытые панели плавно закрываются со своих текущих позиций; повторное открытие продолжает переход без скачка.

Полная сборка включает `mlauncher-overlay.dll` рядом с EXE. После сборки DLL обычный `cargo build` копирует её к EXE и встраивает её SHA-256. Оверлей пропускает скрытые служебные OpenGL-окна и восстанавливает рендерер при пересоздании контекста. Для Oracle `javapath` лаунчер определяет настоящий исполняемый файл через `java.home` и обновляет старый кеш пути Java: DLL подключается к процессу Minecraft. Shift+Tab обрабатывается через сообщения окна и резервный опрос клавиатуры, поэтому короткие нажатия не пропускаются. Диагностика сохраняется в журнал запуска. Изолированный тест проверяет рендеринг, ввод, скрытый начальный контекст, пересоздание контекста и завершение процесса; он не заменяет проверку внутри конкретной сборки Minecraft.

## Запуск

Требуется Rust и системный C/C++ toolchain.

В `rust-toolchain.toml` для этого проекта выбран Windows GNU toolchain, доступный в текущей среде. Поэтому обычный `cargo run` использует MinGW-w64 и не требует MSVC `link.exe`. Глобальный toolchain Rust не меняется.

### Windows MSVC

Если хотите использовать MSVC вместо выбранного для проекта GNU, установите Visual Studio Build Tools с компонентом **Desktop development with C++** и Windows SDK, затем явно укажите toolchain:

```powershell
cargo +stable-x86_64-pc-windows-msvc run
```

### Windows GNU (если уже есть MinGW-w64)

```powershell
cargo +stable-x86_64-pc-windows-gnu run
```

При необходимости сначала установите toolchain: `rustup toolchain install stable-x86_64-pc-windows-gnu`. В этой рабочей среде доступен GNU toolchain, но отсутствует MSVC `link.exe`.

Релизная сборка:

```powershell
cargo build --release
powershell -ExecutionPolicy Bypass -File scripts\package.ps1
```

Готовый архив: `dist\MLauncher-0.3.6-win64.zip`, внутри `MLauncher.exe`, `mlauncher-overlay.dll`, README и лицензии. DLL оверлея должна оставаться рядом с EXE; её хеш проверяется лаунчером. EXE не требует установленного Rust. Для сборки исходников полной версии нужны Rust и x64 MinGW GCC/G++: сценарий упаковки собирает также нативный оверлей.

Иконки можно пересоздать из исходного PNG (16–256 px, прозрачный фон): `powershell -File scripts\make-icon.ps1 -Source "путь\logo.png" -Name icon`. Для встроенной в EXE используется `assets/icon.ico`.

Для повседневного использования запускайте `MLauncher.exe` двойным щелчком. Первый запуск Minecraft скачает библиотеки и ресурсы (сотни мегабайт для современных версий), последующие — заметно быстрее.

## CurseForge

Получите ключ для стороннего клиента согласно [официальной документации](https://docs.curseforge.com/rest-api/). Вставьте ключ в настройки приложения и сохраните (Windows DPAPI, отдельный `api-keys.dat`) либо передайте перед запуском:

```powershell
$env:CURSEFORGE_API_KEY = 'ваш-ключ'
cargo +stable-x86_64-pc-windows-gnu run
```

Чужие ключи не встроены. Если API не предоставляет `downloadUrl`, приложение не вычисляет CDN-ссылку и не обходит ограничения автора: доступно открытие страницы проекта для ручной загрузки. Ручные файлы импортируются через редактор сборки, а установка через API ведёт реестр обновлений.

## Аккаунты и Ely.by

Нажмите иконку пользователя слева от имени или **«+ Добавить аккаунт»** в списке.

- **Обычный (без пароля)**: ник из 3–16 латинских букв, цифр и `_`. Флажок скинов Ely.by сохраняется как настройка, но сам по себе не изменяет Minecraft.
- **Ely.by**: логин/email, пароль и, если включено, шестизначный код 2FA. Прямой Yggdrasil-вход реализован по [документации Ely.by](https://docs.ely.by/en/minecraft-auth.html). Запросы выполняются в фоновом потоке.

Для полноценной версии предпочтителен OAuth2 с регистрацией собственного приложения Ely.by. Текущая версия использует документированный вход по паролю. Access/client-токены сохраняются в `sessions.dat` в зашифрованном виде (Windows DPAPI) и обновляются через `/auth/refresh`; пароль на диск не попадает.

## Microsoft

1. Зарегистрируйте **собственное** приложение в [Microsoft Entra](https://learn.microsoft.com/entra/identity-platform/quickstart-register-app) с поддержкой личных Microsoft-аккаунтов. Разрешите public client flows / device code flow. Client secret не нужен и не используется.
2. Проверьте [требования доступа к Minecraft API](https://minecraft.wiki/w/Microsoft_authentication): для новых приложений может требоваться одобрение Mojang. Без разрешений Minecraft API может возвращать 403 — другой Client ID или обход ограничений приложение не использует.
3. В настройках (иконка меню) укажите Application (client) ID. Он сохраняется в конфигурации как публичный идентификатор. Либо передайте `MICROSOFT_CLIENT_ID` при пустом значении в конфигурации.
4. Нажмите иконку пользователя → **Microsoft** → **Войти через браузер**. На сайте Microsoft введите код с панели лаунчера. Есть копирование кода, повторное открытие сайта и отмена.

Протокол: tenant `consumers`, scope `XboxLive.signin offline_access`, ожидание с интервалом сервера, обработка `authorization_pending`, `slow_down`, отказа и истечения кода, затем Xbox Live / XSTS / Minecraft. После получения токена проверяется наличие Java entitlement и игрового профиля. Пароль Microsoft лаунчер никогда не запрашивает.

Access token Minecraft и refresh token Microsoft хранятся в `sessions.dat`, зашифрованные Windows DPAPI для текущего пользователя; при следующем запуске сессия обновляется автоматически. Открытых токенов нет ни в `config.json`, ни в журналах (строки с токенами редактируются). Удаление Microsoft-аккаунта удаляет локальную сессию, но не отзывает согласие на стороне Microsoft; разрешения можно отозвать в настройках Microsoft-аккаунта. Успешный сквозной вход по-прежнему требует вашего Client ID и одобрения Minecraft API; на реальном аккаунте разработчиком не проверялся. Автотесты проверяют классификацию ответов, отмену, entitlement и шифрованное хранение.

### Скины в игре

При запуске с Ely.by или оффлайн-аккаунтом с включённым флажком скинов лаунчер скачивает [authlib-injector](https://docs.ely.by/en/authlib-injector.html) с официального адреса, проверяет SHA-256 и подключает как `-javaagent:...=ely.by`. Профиль Ely.by подставляется в аргументы игры, поэтому скины работают и на оффлайн-аккаунте. Оффлайн-аккаунт не заменяет Microsoft-лицензию и не открывает доступ к серверам с обязательной онлайн-авторизацией.

## Оформление и фон

Иконка меню → **Оформление**. Тема и цвет применяются сразу; нажмите **«Сохранить»**, чтобы оставить настройки после перезапуска.

- Темы: **Legacy**, **Тёмная**, **Светлая**, **AMOLED**. Акцент можно выбрать из палитры или задать свой.
- Единственная иконка приложения — зелёно-коричневая плитка на основе `ava.png` со строгими геометрическими буквами **ML**, встроенная в EXE и окно. Векторный исходник: `assets/icon-official.svg`; воспроизводимый рендер без внешних сервисов: `scripts/make-brand-icon.ps1`.
- Встроенные эффекты: пейзаж, пузыри, динамическое размытие (мягкие движущиеся цветовые пятна), волны, звёзды, северное сияние, а также оригинальные блочные сцены — **Блочные холмы**, **Кристальная пещера**, **Базальт и лава**, **Острова Края**. Для эффектов выбирается светлая или тёмная подложка, независимо от темы панелей. Цвета эффектов смешиваются с подложкой, поэтому на светлом фоне они не выцветают в белое, а размытие остаётся мягким и не пересвеченным. Флажок **«Анимация фона»** останавливает анимацию; для GIF/видео остаётся текущий кадр.
- Собственная тематическая панель заголовка: перенос окна, сворачивание, разворачивание, закрытие и быстрый доступ к ИИ. Повторный щелчок по кнопке открытой панели закрывает её. Плавные переходы панелей отключаются в оформлении.
- **«Выбрать фон…»** открывает выбор файла. Поддерживаются PNG, JPG/JPEG, WebP, BMP, GIF; для MP4/WebM/MKV/MOV/AVI/M4V нужен **FFmpeg** в `PATH` (`ffmpeg -version`). Автоматического скачивания FFmpeg нет, файлы передаются процессу напрямую, без командной оболочки.
- Пользовательские обои сохраняют исходное разрешение и тайминг GIF/видео, без программного ограничения FPS или уменьшения до 720p/1080p. Размер текстуры ограничивается только возможностями GPU. Видео идёт циклически без звука через FFmpeg (`-re`, PAM RGBA); GIF декодируется встроенной библиотекой. Тайминг GIF учитывает время декодирования, чтобы оно не замедляло воспроизведение.
- Видимые анимации рисуются с VSync; частота текущего монитора учитывается при расчёте времени кадра и обновляется при переносе окна. При сворачивании, скрытии в трей или перекрытии другим обычным окном перерисовка и выдача кадров обоев ограничиваются 30 FPS. Отдельный наблюдатель продолжает проверять состояние скрытого окна каждые 100 мс. Скрытое окно может полностью перестать рисоваться средствами ОС.
- Фон заполняет окно с сохранением пропорций (края могут обрезаться). Есть затемнение и настройка плотности панелей. При ошибке выводится причина в настройках, остаётся сохранённый кадр или нейтральная подложка, а не посторонний стандартный пейзаж.
- GIF/видео декодируются в отдельном потоке. В памяти не хранится весь ролик: очередь ограничена двумя кадрами; при смене фона или выходе декодирование отменяется и запущенный приложением FFmpeg завершается.
- Выбранный файл копируется в `media` внутри каталога данных лаунчера. Кеш кадра хранится в `MLauncher-cache/<редакция>/media` рядом с EXE. Исходник не удаляется. Первый кадр сохраняется как небольшой PNG и загружается до показа окна; видео декодируется параллельно. Повторный запуск не ждёт FFmpeg и не показывает стандартный фон. Для ранее выбранного внешнего файла кеш кадра создаётся после первого успешного воспроизведения. Ссылки на сетевые видео не поддерживаются.
- В списке аккаунтов и возле выбранного аккаунта показываются лица скинов с верхним слоем, отдельно кешируемые от иконок модов. Ely.by запрашивается у системы скинов Ely.by, Microsoft — у Mojang. При отсутствии скина/сети остаётся пиксельное лицо-заглушка.

Иконки модов загружаются отдельно от поиска, без API-ключей в запросах CDN. При недоступной или неподдерживаемой иконке отображается заглушка с первой буквой. Кеш текстур ограничен; SVG-иконки сейчас не растеризуются.

Для новых установок иконка, описание и категории выбранного мода сохраняются в `mods.json` и показываются также в «Мои моды». Старые записи и автоматически добавленные зависимости без метаданных остаются совместимыми и отображаются с заглушкой.

## Размеры встроенных панелей

- Потяните за **верхний, нижний, левый или правый край** панели либо за штрихованный **нижний правый угол**. Это элементы одного основного окна, не отдельные окна операционной системы.
- Ширина и высота основной панели и размеры аккаунтов, настроек, версий, модов, сведений и формы создания сборки запоминаются отдельно в `config.json`. Высоты колонок независимы; изменение правой панели не растягивает левую.
- Размер меняется относительно центра рабочей области и округляется по сетке 8 точек. Есть минимальные размеры и ограничение текущим размером основного окна. При временном уменьшении основного окна сохранённые размеры панелей не затираются — после увеличения они восстановятся.
- Сохранение происходит автоматически после отпускания края; нажатие «Сохранить» для размеров не требуется. Размер основного окна в обычном, не максимизированном режиме также запоминается.
- **Двойной щелчок по границе/углу** или иконка обновления в заголовке сбрасывает размер панели. Настройки → **Аккаунты и сборка → Сбросить размеры панелей** возвращает все панели к исходным размерам, не удаляя сборки или оформление.
- Фильтры сортировки и категории — две равные колонки. Поиск, кнопки, карточки и поля форм подстраиваются под ширину. В модах прокручивается только список: верхние фильтры и нижние кнопки страниц не уходят за край. В списке версий прокрутка также занимает всю доступную высоту.

## Java и запуск Minecraft (бета)

Настройки → **Аккаунты и сборка** → раздел **Minecraft и Java**:

- **Папка установки Minecraft** — по умолчанию используется каталог данных приложения. Можно выбрать любую папку; старые файлы не перемещаются и не удаляются.
- **Java** — путь к `java.exe` (пусто — автоматический подбор). Кнопка «Найти установленные Java» сканирует `%LOCALAPPDATA%`, `Program Files`, `JAVA_HOME` и другие стандартные места.
- **Автоматическая загрузка Java** — если нужная версия не найдена, приложение скачает Temurin (Eclipse Adoptium) с официального API и установит её в папку данных.
- **Память (Xms/Xmx)** и **сборщик мусора** — задаются отдельно. G1GC, ZGC и Shenandoah доступны на Java 17+.
- **Дополнительные JVM-аргументы** — один аргумент на строку; `-Xms`, `-Xmx`, `-cp`, `-jar` и `PermSize` запрещены (память задаётся отдельно).
- **Размер окна** и **полноэкранный режим** — передаются в аргументы запуска.

Для запуска нужны аккаунт (Ely.by, Microsoft или обычный без пароля) и выбранная сборка, включая Vanilla. Нажмите «Запустить» на главной панели. При первом запуске загружаются библиотеки, ресурсы и сам клиент Minecraft; при использовании Ely.by активируется authlib-injector для скинов.

Поддерживаемые загрузчики: **Vanilla, Fabric, Quilt, Forge, NeoForge**. Forge и NeoForge устанавливаются через их официальные установщики (скачиваются и запускаются автоматически).

## Данные


Путь вычисляется через `directories::ProjectDirs`. На Windows обычно `%LOCALAPPDATA%\MLauncher\MLauncher\data`. Иконка папки открывает каталог текущей сборки.

Папка инстанса называется так же, как сборка в лаунчере (`Sborka`, `1.21.1 · Fabric`), а не `profile-N`. Недопустимые для Windows символы удаляются, совпадающие имена получают суффикс `(2)`. При первом запуске новой версии старые папки `profile-N` автоматически переименовываются под текущие названия сборок; содержимое перемещается целиком, ничего не удаляется. Если папка занята Проводником или антивирусом, лаунчер делает несколько попыток и показывает предупреждение — закройте папку и перезапустите его. Если целевая папка уже существует, переименование пропускается.

```text
config.json
instances/
  Sborka/
    mods.json
    mods/
  <название сборки>/
    launcher/
```

### Скорость установки и запуска

- При первом запуске файлы проверяются по SHA-1/SHA-256 во время скачивания, без повторного чтения с диска.
- При последующих запусках уже скачанные файлы пропускаются по размеру, как в официальном лаунчере; повторное хеширование сотен мегабайт не выполняется. Полная проверка выполняется после каждой загрузки.
- Ресурсы (assets) скачиваются в 16 потоков, библиотеки — в 12.
- Найденная автоматически Java кешируется в `metadata/java-<версия>.txt`; повторный запуск не сканирует диск и не вызывает `java -version`.
- Каталог версий Mojang читается из локального кеша без сетевого запроса; authlib-injector и метаданные берутся из кеша.
- Первая установка современной версии всё равно требует скачать сотни мегабайт ресурсов — это ограничение размера игры, а не лаунчера. Повторные запуски должны быть заметно быстрее.
- В `Cargo.toml` зависимости в dev-профиле собираются с `opt-level = 3`, поэтому даже `cargo run` не выполняет SHA-хеширование и декодирование изображений в медленном debug-режиме. Для повседневного использования всё равно рекомендуется `cargo run --release` — он ещё быстрее.

Версия и загрузчик закреплены за инстансом и не изменяются на месте: выбирайте другую версию или создавайте другую сборку. Для скачанных сборок также сохраняется точная версия загрузчика из манифеста. Старые инстансы и их файлы сохраняются. Моды нельзя устанавливать в Vanilla-инстанс. Решения всех конфликтов между модами пока нет. Не используйте бету для изменения единственной копии ценной сборки. Запуск игры защищён блокировкой общего каталога установки; изменения конфигурации из нескольких экземпляров одновременно не поддерживаются.

### Выбор версий и сборок

Нажмите иконку куба на основной панели или **«Все версии…»** в списке сборок. В каталоге доступны все записи официального манифеста, включая `old_alpha`, `old_beta`, снапшоты, pre-release и release candidate (последние классифицируются так, как их классифицирует Mojang). Состояния четырёх фильтров автоматически сохраняются при переключении.

- **Номер версии** — выбрать или создать отдельный Vanilla-инстанс этой версии.
- **Иконка плюса** — выбрать загрузчик и название сборки. Создаётся отдельный пункт в списке инстансов.
- Флажок создания ещё одной сборки позволяет иметь, например, два независимых Fabric-инстанса для 1.21.1.
- Иконка модов (четыре квадрата) в Vanilla предлагает создать отдельный модифицированный инстанс, не меняя Vanilla.

### Мои сборки

Вкладка **«Мои сборки»** в окне «Версии и сборки» показывает все сборки лаунчера и их папки:

- **Сделать активной** — выбрать сборку и вернуться на главный экран.
- **Переименовать** — изменить название. Папка переименуется автоматически (если не занята Проводником/антивирусом; иначе появится предупреждение).
- **Открыть папку** — показать файлы сборки в Проводнике.
- **Удалить** — убрать сборку из лаунчера, сохранив папку, либо удалить папку с файлами безвозвратно (отдельный флажок в подтверждении).
- **Создать сборку** — вернуться в каталог версий.

Если папка сборки удалена вне лаунчера, при запуске и при открытии «Моих сборок» такая запись исчезает из меню. Кнопка **«Проверить папки»** запускает проверку вручную. Папки создаются сразу при добавлении сборки, поэтому новая запись не пропадает.

Например, `b1.7.3 · Vanilla`, `1.21.1 · Vanilla`, `1.21.1 · Fabric` и `1.20.1 · Forge` имеют разные папки `instances/<название>/` — моды, миры и настройки не смешиваются.

Наличие Alpha/Beta/Snapshot в списке означает, что версия есть в официальном каталоге Mojang, но не гарантирует современный загрузчик или моды. Для очень старых версий может потребоваться Java 8; автоскачивание Temurin 8 предусмотрено. Forge/NeoForge устанавливаются официальными установщиками — на экзотических версиях возможны их собственные ограничения.

## Проверки

### Lite

Отдельная облегчённая сборка: `powershell -ExecutionPolicy Bypass -File scripts\package.ps1 -Lite`, архив `dist\MLauncher-Lite-<версия>-win64.zip`. Без видео/FFmpeg, тяжёлых сцен, мультисессий, нативного оверлея, ручного CurseForge и стартовой предзагрузки каталогов. DLL в Lite не собирается и не включается. Остаются фото/GIF, акцент, простые фоны (волны, пузыри, сияние) и анимация открытия/закрытия вкладок, а также основные функции запуска/модов/сборок/ресурспаков. Данные изолированы от полной версии. Подробнее: [README-Lite.md](../README-Lite.md).

### Мульти-Сессии и нативный оверлей (экспериментально)

В **Настройках → Мульти-Сессии** можно разрешить до 8 параллельных клиентов из одного лаунчера. Для каждого нужна **отдельная сборка/папка**: одновременная запись двух Minecraft в один мир/настройки небезопасна и запрещена. Создайте копии заранее через экспорт/импорт или используйте разные сборки. Выберите другую сборку в главной панели и нажмите «Запустить». Подготовка общих библиотек выполняется по очереди, сами игры работают одновременно. Остановка каждой сессии — в этом же разделе настроек.

Профиль экономии задаёт отдельный лимит памяти на клиент (по умолчанию 2048 МиБ), минимум 256 МиБ, окно 854×480 и отключает fullscreen. Пользовательские Java-аргументы сохраняются. Это не гарантия достаточности памяти для тяжёлых сборок; учитывайте дополнительную память JVM, GPU и ОС. Одна учётная запись может иметь ограничения серверов на одновременные входы. Полный игровой запуск нескольких клиентов не проверен автоматически.

**Внутриигровой оверлей** включается отдельным флажком в настройках для **следующих запусков**. Это нативная DLL, внедряемая только в Java-процесс, запущенный этим лаунчером, а не Minecraft-мод и не отдельное окно. **Shift+Tab** открывает/закрывает интерфейс внутри игрового кадра; **Esc** закрывает. Доступны поиск/сортировка ресурспаков Modrinth/CurseForge, скачивание совместимой версии в текущую сборку и журнал именно этой сессии. Для CurseForge по-прежнему нужен пользовательский API-ключ. После скачивания включите ресурспак в настройках Minecraft. Пока оверлей скрыт, журнал не опрашивается. Лаунчер должен оставаться открытым.

Первая версия поддерживает **Windows x64 / WGL / OpenGL 3+**. **Vulkan и VulkanMod НЕ поддерживаются** — предупреждение добавлено также в «О проекте». Перехват больше не зависит от имени класса окна, а горячая клавиша дополнительно опрашивается через `GetAsyncKeyState`, поэтому Shift+Tab работает и в NeoForge/GLFW, если игра не блокирует ввод. Оформление оверлея использует акцент, тему и простой фон лаунчера; щелчок вне окна закрывает его. Возможны конфликты с другими оверлеями, модами пересоздания графического контекста, защитным ПО и античитами; защиты не обходятся. При проблемах отключите флажок и перезапустите клиент. Старый флажок окна-компаньона не включает внедрение автоматически. Полная совместимость с Minecraft, эксклюзивным fullscreen, всеми загрузчиками и античитами не подтверждена; нативный тест использует отдельный OpenGL-host. Детали, зависимости и воспроизводимая проверка: [native/README.md](../native/README.md).

Ресурспак скачивается **одной кнопкой** с карточки (последний совместимый выпуск), без галочки, в том числе при запущенной игре. Активировать/перезагрузить его нужно в настройках Minecraft. Реестр `launcher/resources.json` сохраняет проект, версию и файл; повторное скачивание проверяет хеш и не перезаписывает изменённые пользователем файлы. Ранее скачанные файлы без реестра распознаются при повторном запросе по хешу.

При запуске в фоне загружаются первые страницы Modrinth для сборок и ресурспаков выбранной версии Minecraft. До 20 карточек страницы и небольшие аватарки кешируются в `MLauncher-cache/<редакция>` рядом с EXE. Кеш показывается до обновления сети; скачивание всегда использует актуальные метаданные и проверку хеша. Ключи и учётные записи в кеш карточек не записываются.

**CurseForge: ручная загрузка** — экспериментальный флажок в настройках. В разделе модов открывается официальный сайт **в системном браузере**, затем пользователь выбирает скачанный JAR и подтверждает доверие. Встроенный мини-браузер пока не реализован. Совместимость и зависимости нужно проверить самостоятельно; импорт во время игры запрещён. Ручные JAR остаются локальными файлами в `mods`, без автоматических обновлений. Запреты CDN, CAPTCHA и ограничения API не обходятся.

```powershell
cargo fmt -- --check
cargo test
cargo clippy --all-targets -- -D warnings
cargo run -- --smoke-test
cargo run -- --content-smoke-test
cargo run -- --catalog-smoke-test
cargo run -- --loader-smoke-test
```

`--smoke-test` проверяет Mojang, моды Modrinth и медиадекодеры. `--content-smoke-test` проверяет каталоги/версии Modrinth, ATLauncher, FTB, Technic, устанавливает настоящий mrpack Fabulously Optimized и ресурспак, затем выполняет полный и индексированный экспорт/импорт с побайтовым сравнением файлов. Все данные временные. CurseForge без `CURSEFORGE_API_KEY` пропускается.

`--loader-smoke-test` ставит Fabric 1.20.1, Forge и NeoForge 1.21.1, скачивает библиотеки и проверяет classpath, но не запускает Minecraft и не входит в аккаунты. Для установщиков нужна найденная Java 21. Это не сквозной тест игры или всех сборок.

## Сборки и ресурспаки

Сборки находятся в **«Версии и сборки»**, ресурспаки — во вкладке **«Моды и ресурспаки»**. Отдельной панели загрузок нет:

- **Версии** — каталог Minecraft; **Мои сборки** — управление установленными сборками.
- **Сборки** — поиск и скачивание сборок; **Импорт / экспорт** — перенос собственных сборок.
- **Моды → Ресурспаки** — поиск Modrinth/CurseForge для выбранной сборки и скачивание в её `resourcepacks`. Доступно и для Vanilla.
- Карточки сборок и ресурспаков показывают аватарку, название, автора/источник, число скачиваний (если доступно) и описание. Иконки догружаются в фоне. При недоступном изображении остаётся тематическая заглушка.
- У сборок и ресурспаков есть та же сортировка, что у модов: по скачиваниям, релевантности, обновлению и дате выхода. Недоступные конкретному каталогу режимы отключены.
- Установленная сборка получает название проекта из каталога, а не только номер версии. Версия сборки сохраняется в `launcher/pack-info.json` вместе с источником.
- Поиск, выбор выпуска для скачивания, открытие страницы, импорт, экспорт, подтверждение и отмена обозначены иконками с подсказками. Важное подтверждение доверия к исполняемым модам сохранено. Длинные пояснения перенесены в подсказки.
- Каталоги **Modrinth, CurseForge, ATLauncher, FTB, Technic** с выбором конкретного выпуска. Установка всегда создаёт отдельную папку и запись после успешного завершения. Старые сборки не перезаписываются.
- **Modrinth**: импорт `.mrpack`, загрузки по индексу, хеши, client-overrides и точная версия загрузчика.
- **CurseForge**: официальный API с вашим ключом, импорт manifest ZIP. При запрете `downloadUrl` установка останавливается, запреты не обходятся. Реальная установка требует вашего ключа и отдельно не подтверждена без него.
- **FTB**: публичный каталог и манифесты, клиентские файлы, хеши и закреплённый загрузчик. Совместимость конкретных сборок с новым API или игрой не гарантируется.
- **ATLauncher (экспериментально)**: публичные сборки с прямыми/server-загрузками, конфигурационный ZIP. Browser/manual-загрузки и нестандартные типы модов требуют дальнейшей поддержки; установка в таком случае прерывается.
- **Technic (экспериментально)**: Solder-выпуски с явно указанной версией Forge в списке компонентов. Используется официальный установщик Forge вместо чужого `bin/modpack.jar`. Старые патченные JAR и прямые ZIP без метаданных загрузчика не поддерживаются. FTB/ATLauncher/Technic проверены на каталог/список выпусков, не на полный игровой запуск.
- **Ресурспаки** Modrinth/CurseForge фильтруются по Minecraft выбранной сборки и скачиваются в её `resourcepacks`. Включаются внутри Minecraft. Установка доступна и для Vanilla; раздел находится во вкладке «Моды и ресурспаки».
- **Полный экспорт**: ZIP содержит все моды, ресурспаки, конфигурацию и скрипты сборки. **Индексированный**: моды с точными URL/версиями и контрольными суммами скачиваются на другом компьютере. Ресурспаки с известным источником также индексируются, встроенные файлы без отдельного источника остаются в ZIP. Если источник мода неизвестен или файл изменён, экспорт не теряет его молча: предлагает полный вариант.
- Собственный формат — `mlauncher-pack.json` + `files/` в ZIP. Импортируется этим лаунчером; это не обещание совместимости с другими лаунчерами. Миры, журналы, аккаунты и API-ключи в экспорт не входят. Конфигурации модов проверьте на личные данные самостоятельно. Соблюдайте лицензии модов при распространении полного архива.
- Архивы проходят проверку путей, ссылок, дубликатов и лимитов распаковки. Установка и экспорт отменяются; при сбое временная папка удаляется. Прерывание процесса/выключение ПК может оставить временные файлы. Неизвестные Java-моды всё равно являются исполняемым кодом — подтверждайте только доверенные источники.

## ИИ-диагностика

«Настройки → Сервисы» содержит URL совместимого Chat Completions API, модель и ключ.
Ключ хранится в Windows DPAPI, для удалённого API нужен HTTPS, для localhost допускается HTTP.
Помощник поддерживает отдельный текстовый разбор отчёта и выполнение структурированных действий.
Правила автоматизации описаны в разделе «Автоматические действия ИИ» ниже.

## Обновления лаунчера

Полная и Lite-версии для Windows x64 при запуске проверяют публичные релизы
MixiYT/MLauncher на GitHub. Архив новой версии скачивается в папку
`updates` внутри каталога данных лаунчера и проверяется по SHA-256 от GitHub.
В настройках можно повторить проверку и открыть папку со скачанным архивом.
После завершения игры и активных загрузок лаунчер закрывается, обновляет файлы и запускается снова. В папке с ограниченными правами можно установить обновление вручную из скачанного архива.

При публикации следующей версии увеличьте версию в `Cargo.toml`, соберите обе
редакции скриптом `scripts/package.ps1` (для Lite добавьте `-Lite`) и приложите
к опубликованному релизу оба архива с именами
`MLauncher-X.Y.Z-win64.zip` и `MLauncher-Lite-X.Y.Z-win64.zip`.
Тег релиза должен быть `X.Y.Z` или `vX.Y.Z`.


## Liquid Glass

Фон захватывается на GPU после отрисовки сцены и до панелей. Текстура уменьшается в четыре раза по каждой оси, затем шейдер применяет размытие 5×5, скруглённую маску и небольшое смещение преломления у краёв. Текст и элементы управления рисуются поверх размытия. Ресурсы пересоздаются при изменении размера и освобождаются в on_exit. При недоступности шейдера остаются полупрозрачные поверхности. Рендерер требует OpenGL 3.3.

## Автоматические действия ИИ

Пользователь запускает запрос в помощнике. Настройки endpoint и model совместимы с Chat Completions API.
Модель возвращает JSON с одним из действий create, repair или launch. JSON проверяется по закрытой схеме.
Создание допускает Vanilla, Fabric, Quilt, Forge и NeoForge, от 1024 до 16384 МиБ памяти и до 40 модов.
Идентификаторы модов разрешаются через Modrinth, загрузки проходят обычную проверку совместимости, зависимостей и хешей.

Исправление может устанавливать моды, обновлять зарегистрированные JAR, отключать перечисленные JAR, сбрасывать options.txt и параметры Java.
Произвольные команды, пути и скрипты в план не входят.
Создание выполняется во временной папке. Исправление работает с копией mods и метаданных, а перед заменой сохраняет исходные файлы
в launcher/ai-backups/<UUID> внутри сборки. При ошибке применения файлы откатываются. Журнал транзакции позволяет восстановить исходные файлы перед следующим запуском игры, если приложение завершилось посреди замены. Во время работы игры изменение сборки блокируется .session.lock.
Кнопка отката в помощнике восстанавливает последнюю резервную копию текущего сеанса.

Автоисправление относится к игре, запущенной из ИИ-запроса. Можно разрешить от одной до трёх повторных попыток.
После каждого неудачного запуска отправляется очищенный журнал и состояние сборки, без ключей и токенов.
Во время ИИ-запуска лаунчер остаётся открытым для наблюдения за процессом. При отмене, штатном завершении игры или исчерпании лимита цикл останавливается.
Наличие подходящих версий модов, доступ к выбранному ИИ API и действующий аккаунт проверяются обычными средствами лаунчера.

Общий ИИ, Cloudflare Worker, пул ключей и публичные микропатчи описаны в [AI-GATEWAY.md](AI-GATEWAY.md).
